# Wrapped Up

A focused, one-page website for Wrapped Up, a confidential Christian brotherhood for men seeking freedom from lust, sexual temptation, and secrecy.

## Run it locally

The site has no build step, package manager, framework, tracking, or application runtime.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173`.

## Files

- `index.html` contains the page structure and final copy.
- `styles.css` contains the complete responsive visual system.
- `assets/wrapped-up-logo.png` is the primary supplied logo used in the hero.
- `assets/wrapped-cross.png` and its smaller variants provide the compact brand mark used in the header, footer, and browser icons.
- `assets/social-card.png` is the 1200 × 630 preview image used by iMessage and social platforms.
- `assets/wrapped-up-logo-512.png` provides the square organization logo used by search metadata.
- `robots.txt` and `sitemap.xml` provide search-engine crawl and discovery guidance.

## Privacy

The site has no analytics, cookies, or local visitor data storage. Google Fonts provides the three typefaces used by the design.

The contact form is delivered through FormSubmit to `info.wrappedupfl@gmail.com`. FormSubmit requires no account. The recipient must click the activation link sent after the first submission before regular inquiries are delivered.
