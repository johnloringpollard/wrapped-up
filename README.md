# Wrapped Up

A focused, one-page website for Wrapped Up, a confidential Christian brotherhood for men seeking freedom from lust, sexual temptation, and secrecy.

## Run it locally

The site has no build step, package manager, framework, tracking, or application runtime.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173`.

## Files

- `index.html` contains the page structure and final copy.
- `styles.css` contains the complete responsive visual system.
- `assets/mark.svg` and `assets/favicon.svg` are original cord-based brand marks created for the site.

## Privacy

The site has no analytics, cookies, form submissions, or visitor data storage. Google Fonts provides the three typefaces used by the design.
