# Wrapped Up

A focused, one-page website for Wrapped Up, a confidential Christian brotherhood for men seeking freedom from lust, sexual temptation, and secrecy.

## Run it locally

The site has no build step, package manager, framework, tracking, or remote runtime dependency.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Then open `http://127.0.0.1:4173`.

## Files

- `index.html` contains the page structure and final copy.
- `styles.css` contains the complete responsive visual system.
- `script.js` adds progressive enhancements for the four circles, personal guardrail list, active navigation, and private page sharing.
- `assets/mark.svg` and `assets/favicon.svg` are original cord-based brand marks created for the site.

## Privacy

The site has no analytics, cookies, form submissions, or third-party requests. Guardrail selections are saved only in the visitor's own browser using local storage. They are never transmitted.

## Before adding a direct contact action

The current invitation uses person-to-person sharing because no verified group email, meeting time, address, form endpoint, or confidentiality policy was supplied. Confirm those details before adding them to the public page.

The four circles are written as a practical Circle 4 to Circle 1 framework based on the supplied description. The group should confirm the names and language against its actual weekly practice.
